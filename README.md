## 🔍 What OPFV does

OPFV helps you look at future results when conditions change over time. It is made for users who want to study how a system may behave later, even when the data does not stay the same.

You can use it to:

- explore future value estimates
- compare results across time
- test how learning methods handle change
- work with non-stationary data
- review results in a simple local app

## 🧭 How to use it

1. Start the app.
2. Load the data file you want to use.
3. Choose the method you want to test.
4. Set the time range or future window.
5. Run the evaluation.
6. Review the output on the screen.
7. Save the result if you want to keep it.

## 🛠️ If Windows blocks the file

If Windows shows a warning:

1. Click More info.
2. Click Run anyway.
3. If the file came in a zip folder, make sure you extracted it first.
4. Keep the file in a folder you can access, such as Downloads or Desktop.
